## 二、省 / 市 / 县三级（公开数据缺口）

经检索，**没有公开、完整、逐年更新的省—市—县三级废纸回收统计**：
- 中国造纸协会年度报告、再生资源回收行业报告主要公布**全国**口径；
- 部分行业分析只到**大区**（如华东、华南集中度较高），无法拆到市、县；
- 地方造纸/再生资源协会偶有单省数据，但口径不一、不成体系。

因此本项目对省/市/县采用**分层测算**：
- 以 2024 年全国回收量 6971 万吨为总量；
- 按各省产业规模的相对权重分摊到省，再按市、县逐级分摊；
- 每条数据带 `provenance` 字段，界面明确标注「官方」或「分层测算」。

## 三、如何替换为真实数据

真实统计到位后，只改 `src/paper_recycle_agent/regions.py` 里的 `_RAW`（或改为读取 JSON/Excel），
下钻、汇总、Excel 导出逻辑无需改动。建议的真实数据字段：
`省 / 市 / 县区名称、行政区划代码、回收量(万吨)、回收率(%)、利用率(%)、企业数、从业人员`。

> 结论：**国家数字是真实的，省市县是占位测算**。这不是偷懒，而是公开数据本身只到全国层面；
> 谁也不可能凭空给出全县级的真实废纸回收量。
