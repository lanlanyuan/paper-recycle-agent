## 三、省级（报道 + 测算，不可直接作为统计公报数据）

经检索，**没有公开、完整、逐省逐年更新的废纸回收统计**。现有公开信息的颗粒度是：

- **山东 763 万吨、广东 733 万吨**（2024，行业研究机构公开报道）——已按 `reported` 录入；
- 河南、江西、浙江、江苏 **均 >500 万吨**；
- 湖北、四川、福建、重庆、安徽、广西、北京 **200–500 万吨**；
- 上海、贵州、湖南、山西 **100–200 万吨**；
- 其余省份较少。

因此本项目把省级分成四个梯队，梯队内按行政区划代码做确定性微调，再**归一化**使 34 省合计严格等于
全国官方总量 6971 万吨（`tests/test_regions.py::test_province_sum_equals_national_total` 会校验这一点）。

- 节点字段 `quality`：`reported`（回收量为报道值）/ `estimated`（梯队测算）；
- 节点字段 `provenance` 与界面徽标同步显示；
- 省级的回收率、利用率、企业数、从业人员**全部为测算值**，仅用于展示结构。

## 四、八大类分类回收量（估算）

GB/T 20811-2018 只规定**分类技术要求**，官方**不逐类公布回收量**。本项目给出的分类回收量是：

```
某类回收量 = 该年该大类占比 × 该年官方回收总量
```

占比取自行业结构经验值，并在 2015 / 2020 / 2025 三个锚点上定义，其余年份线性插值：

| 大类 | 2015 | 2020 | 2025 | 变化逻辑 |
| --- | --- | --- | --- | --- |
| 1 废瓦楞纸箱类 | 52.0% | 56.0% | 58.0% | 电商快递拉动，占比持续上升 |
| 2 废纸盒及废卡纸类 | 8.0% | 8.0% | 8.0% | 基本稳定 |
| 3 包装废纸类 | 6.0% | 6.0% | 6.0% | 基本稳定 |
| 4 废新闻纸类 | 13.0% | 7.0% | 3.5% | 报纸发行量萎缩，快速下滑 |
| 5 废书刊杂志类 | 9.0% | 7.0% | 5.0% | 纸质书刊阅读量下降 |
| 6 办公废纸类 | 4.0% | 4.0% | 4.0% | 基本稳定 |
| 7 特种废纸类 | 3.0% | 3.0% | 3.0% | 量小价高 |
| 8 混合废纸类 | 5.0% | 9.0% | 12.5% | 垃圾分类后低值可回收物混入增多 |

货值 = 回收量 × 参考价，仅为量级参考，不是实际成交额。

## 五、为什么不提供市、县数据

市级、县级废纸回收量没有公开的权威逐级统计。v1.2.x 曾用权重分摊「造」出市、县数据，
使用者容易误以为是真实统计。**v1.3.0 起已下线市县两级**，只保留可核验的全国 + 省级。

## 六、已知口径差异（不隐藏）

- **2024 年全国回收量**：中国造纸协会年度报告为 **6971 万吨**；部分行业机构按 **6797 万吨**（同比 +9.1%）统计。
  本项目采用协会口径，并在导出「数据说明」表中写明。
- **2025 年回收量**：协会 2025 年数据为 **7195 万吨 / 回收率 51.8%**；早期预测值曾为 7090 万吨 / 51.1%。
  本项目采用实际值，并标注「初步核算」。
- **2016 年消费量**：部分年鉴统计口径为 10419 万吨，与其他年份不可比，故留空。

## 七、如何替换为真实数据

| 要替换的内容 | 修改位置 |
| --- | --- |
| 某省真实回收量 | `src/paper_recycle_agent/regions.py` 的 `SEEDS`，把该省的 `tier` 改为 `"reported"` 并填 `reported=数值` |
| 历年序列 | `src/paper_recycle_agent/stats.py` 的 `HISTORY` |
| 废纸进口 | `stats.py` 的 `IMPORT_SERIES` |
| 八大类占比 | `stats.py` 的 `CATEGORY_SHARES`（可加锚点年份） |
| 参考价 | `knowledge.py` 的 `value_per_kg`、`stats.py` 的 `CATEGORY_META[*]["price"]` |
| 投入产出矩阵 | 把国家统计局 42 部门表导出为 `data/io_matrix.csv`（格式见 `data/io_matrix.csv.example`） |
| 造纸行业营收 / 产量 | `io_table.py` 的 `NATIONAL_IO` 与 `REVENUE_SERIES` |

改完跑 `pytest -q` 即可，汇总、归一化、图表与 Excel 导出逻辑都不用动。

## 八、企业维度（示例数据，可替换）

**公开数据现状**：没有面向全社会的废纸回收企业逐家回收量公开统计。可获得的公开信息是：
企业名录（工商登记、协会会员名单）、部分上市公司年报的原料采购量、个别园区的招商资料。
逐家企业的年回收量属于商业数据，通常不公开。

因此本项目：
- 内置 **30 家示例企业**（名称虚构），覆盖 15 个省级行政区、4 种类型，用于演示数据结构与分析能力；
- 每条记录 `is_demo = True`，界面显示「示例」徽标，Excel「企业名录」表有「数据性质」列；
- 摘要给出**名录覆盖率**（企业合计 ÷ 该省官方回收量），明确这是样本而非全量；
- 把 `data/enterprises.csv.example` 复制为 `data/enterprises.csv` 并填入真实名录，启动即切换，
  `is_demo` 自动变为 False。

CSV 字段：

| 字段 | 说明 |
| --- | --- |
| id | 企业编号，唯一 |
| name | 企业名称 |
| province_code | 省级行政区划代码，如 370000（山东） |
| city | 所在城市 |
| type | 回收站点 / 分拣打包中心 / 造纸企业 / 贸易商 |
| categories | 主营大类代码，分号分隔，如 `1;8`（废瓦楞纸箱类 + 混合废纸类） |
| volume | 年回收量（万吨） |
| lat / lon | 纬度 / 经度；留空则按省会坐标自动落点 |
| note | 备注 |

**为什么值得有这一层**：区域统计回答「一个地方有多少量」，企业维度回答「这些量由谁在做、
分布在哪些城市、各品类由哪类企业消化」。后者才是统计局核查、协会统计、回收企业找货源的抓手。

**使用注意**：企业样本的合计不应超过所在省官方回收量（有测试守着）；若超过，说明名录口径
与统计口径不一致（例如把贸易商的转手量重复计算），需要先对齐再入库。

## 九、投入产出与消耗金额（分四级标注）

### 9.1 先说一个事实：企业投入产出表不存在

投入产出表（Input-Output Table）是**国民经济核算工具**，编制主体是国家或地区统计局，
用来刻画各产业部门之间的中间投入与最终使用关系。企业层面没有这种表——企业的法定报表是
资产负债表、利润表、现金流量表。因此本项目的四级口径里，真正有官方表可依的只有前两级。

同样地，国家统计局在公开咨询答复中明确：**目前地级市暂不编制投入产出表**。
投入产出表只到国家与省级两个层级。

### 9.2 四级口径对照表

| 层级 | 官方投入产出表 | 数据性质 | 金额怎么算 |
| --- | --- | --- | --- |
| 全国 | ✅ 有（2023 年，42 部门） | 官方 | 废纸消耗量 × 加权参考价 |
| 省级 | ✅ 有（各省编表年份不一） | 官方（表）+ 估算（分摊） | 全国金额按省级回收量分摊 |
| 市级 | ❌ 不编制 | 估算 | 按企业名录的城市分布分摊 |
| 企业 | ❌ 不存在 | 示例 | 年经手量 × 市场均价 |

`io_table.LEVELS` 中每项都带 `io_available` 布尔值与 `note`，界面和 Excel 直接展示，
不会让人误以为「市级金额」是查表得来的。

### 9.3 全国口径的输入参数

| 指标 | 数值 | 来源 |
| --- | --- | --- |
| 废纸消耗量（2024） | 7030 万吨 | 中国造纸协会年度报告 |
| 加权参考价（2024） | 888.5 元/吨 | 八大类参考价按回收量加权 |
| 废纸货值（2024） | 624.6 亿元 | 7030 × 888.5 ÷ 10000 |
| 造纸和纸制品业营业收入（2024） | 14600 亿元 | 中国造纸协会年度报告 |
| 直接消耗系数 | 4.28% | 624.6 ÷ 14600 |
| 单位产值消耗 | 0.482 吨/万元 | 7030 万吨 ÷ 14600 亿元 |
| 投入产出表年份 | 2023（42 部门） | 国家统计局 |

### 9.4 金额为什么标「下限」

888.5 元/吨是**居民/回收站口径**的回收参考价。纸厂实际到厂价还要叠加分拣、打包、运输，
通常更高。项目**不乘任何加价系数**——那会引入一个没有出处的假设——而是把结果标为
`is_lower_bound = True`，在界面、Excel「投入产出」表和文档三处写明：

> 按回收参考价计价，是纸厂废纸成本的下限，不含分拣打包运输。

因此 624.6 亿元应读作「废纸货值下限」，不是「纸厂废纸采购总额」。

### 9.5 为什么不内置投入产出矩阵

`data/io_matrix.csv` 默认不存在，`.gitignore` 也排除了它。理由：编一张看起来权威的假矩阵，
比不提供更糟。算法（Leontief 逆矩阵、影响力系数、感应度系数）已经实现并有用教科书例子
验证的测试，数据请自行从国家统计局 42 部门表导出。

CSV 格式（`data/io_matrix.csv.example` 有样例）：

```
部门名称,部门1,部门2,...
部门1,0.12,0.03,...
部门2,0.05,0.21,...
```

第一列是行标签，第一行是列标签，其余为**直接消耗系数矩阵 A**。导入后即可计算
`(I - A)^-1`、影响力系数与感应度系数。

### 9.6 地图与坐标

- 底图仅用持牌服务商（本项目默认腾讯地图 GL JS），不自行绘制国界；
- 代码不内置任何可用密钥，通过环境变量 `TMAP_KEY` 注入；
- 无密钥时降级为省份排行，不画边界、不报错；
- 省份坐标采用 **GCJ-02**（腾讯地图坐标系），不是 WGS-84。

### 9.7 模型 API（不影响数据口径）

`config/llm.json` 只存连接参数（base_url / model / api_key），不参与任何数据计算。
大模型回答时会被注入一段数据口径说明并要求「不要自行编造数字」，但**它给出的任何数字
都不应替代本文件的官方口径**。该文件已在 `.gitignore` 中，密钥不入库。
