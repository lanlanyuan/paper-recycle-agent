# 工厂碳核算 Agent · 架构与国标依据

> 版本：v1.9.0 · 分支：`feature/carbon-agent`
> 本模块是造纸工厂多智能体系统的**核心 Agent**

## 一、这次重构改了什么（定位变化）

| 模块 | 原来的定位 | 现在的定位 |
| --- | --- | --- |
| 废纸回收对话助手 | 项目主角 | 工厂内的**废纸回收子 Agent**，保留全功能，回收量喂给碳核算 |
| 投入产出表 `io_table.py` | 独立功能模块 | 抽出一个模块作为**方法论参考**：直接消耗系数 / Leontief 逆 → 环境扩展投入产出（EEIOA） |
| `mill/` 智能工厂 | 智能工厂仿真 | 工厂的**工艺智能体群**（制浆/抄纸/干燥/质检） |
| `brain/` 产业大脑 | 五链贯通仿真 | 工厂的**经营管理层**（五域联动） |
| **`carbon/` 碳核算** | 无 | **核心 Agent**：国标方法核算工厂温室气体排放 |

废纸回收助手原来的分类、估价、区域/历年/分类统计、Excel 导出**全部保留**，
界面上作为独立标签页入口，不破坏任何既有功能。

## 二、国标依据（核算方法的出处）

核心依据：**《温室气体排放核算与报告要求 造纸和纸制品生产企业》**
（GB/T 报批稿，全国碳排放管理标准化技术委员会 SAC/TC 548 归口）。
本地留存提取文本于工作区 `gb_carbon_extract.md`（PDF 原件来自国家标准全文公开系统）。

### 核算边界（国标 4.2 / 5.1）

```
企业排放总量 = 化石燃料燃烧 + 过程排放 + 废水厌氧甲烷
             + 购入电力 + 购入热力 − 输出电力 − 输出热力
```

纳入重点排放单位门槛（生态环境部 2023—2025 通知）：
造纸行业年排放 2.6 万吨 CO₂e 及以上（综合能耗约 1 万吨标煤）。

### 五类排放源与公式（逐条对应国标正文）

| 排放源 | 公式 | 国标条款 |
| --- | --- | --- |
| 化石燃料燃烧 | `EF = CC × OF × 44/12`；`AD = FC × NCV`；`E = Σ(AD×EF)` | 公式 2/3/4 |
| 过程排放 | `E = 石灰石消耗量 × 0.405` | 公式 5 |
| 废水厌氧甲烷 | `E = (TOW−S)×0.25×0.5×GWP − 回收量×GWP` | 公式 8/9 |
| 净购入电力 | `E = (购入−输出)电量 × EF电` | 公式 10/12 |
| 净购入热力 | `E = (购入−输出)热力 × EF热` | 公式 11/13 |

### 排放因子（国标附录B 表 B.1/B.2/B.3，逐条带出处）

- **燃料**：低位发热量 NCV、单位热值含碳量 CC、碳氧化率 OF 全部取自表 B.1，
  上标来源分别为《中国能源统计年鉴 2013》《省级温室气体清单指南（试行）》、
  《2006 年 IPCC 国家温室气体清单指南》、行业经验数据。
  例：烟煤 NCV 19.570 GJ/t、CC 26.1×10⁻³ tC/GJ、OF 93% → EF 0.089001 tCO₂/GJ。
- **石灰石分解因子**：0.405 tCO₂/t（表 B.2）。
- **废水厌氧**：最大甲烷生产能力 0.25 tCH₄/kgCOD、修正因子 0.5（表 B.3）。
- **热力缺省因子**：0.11 tCO₂/GJ（正文 5.2.5.3）。
- **电力因子**：国标要求「选用国家主管部门最近年份公布的数据」，
  因此**不内置可能过期的数值**——必须由用户在界面填入并标注年份。
  未配置时总量显示「待配置」，`incomplete=True`，不假装算出完整结果。

`factors.py` 的 `all_factors()` 接口把上述每一项连同来源返回给界面，可逐条核查。

## 三、口径纪律（这是本项目一贯的底线）

1. **活动数据是示例输入**：内置一家示例造纸厂的煤/电/石灰石用量，**不是任何真实工厂的实测值**，
   界面和返回值都标注「示例（仿真输入，非真实工厂）」。
2. **电力因子不内置**：避免用一个可能过期的数字冒充权威值。
3. **范围三单列**：废纸回收的原料替代减排量单列展示，
   **不并入**国标核算总量（国标边界不含范围三），避免口径混淆。
4. **投入产出法只做方法演示**：`supply_chain_carbon_demo()` 提供
   `C = c × (I−A)⁻¹ × y` 的算法骨架，未配碳强度向量与最终需求时
   **返回「不做无数据推算」**，不编造供应链碳足迹。
5. **减排系数标演示**：废纸替代原生浆的 0.85 tCO₂e/t 明确标注为文献量级演示系数，
   正式核算须按浆种/工艺实测确定。

## 四、可由评审手算复核的样例

最小案例（已写进 `tests/test_carbon.py`）：

```
烟煤 1000 t：1000 × 19.570 GJ/t × 0.089001 tCO₂/GJ = 1741.75 tCO₂
石灰石 1000 t：1000 × 0.405 = 405 tCO₂
外购热 1000 GJ：1000 × 0.11 = 110 tCO₂
合计（电力因子0.5、购入电0）：2256.75 tCO₂e
单位产品碳强度：2256.75 ÷ (1万吨×10000) = 0.2257 tCO₂e/吨纸
```

每个结果项都带 `formula` 与 `source` 字段，`tests/test_carbon.py` 用断言钉住这些数值。

## 五、接口与演示

| 接口 | 作用 |
| --- | --- |
| `GET /api/carbon/factors` | 因子表（带出处）与公式 |
| `GET /api/carbon/state` | 核算结果 + 活动数据 + 回收Agent状态 |
| `POST /api/carbon/activity` | 改活动数据并重算 |
| `POST /api/carbon/scenario` | 情景模拟对比 |
| `POST /api/carbon/reset` | 恢复示例数据 |
| `POST /api/carbon/bridge-recycle` | 从回收 Agent 取回收量（行业口径，仅参考不覆盖单厂值） |

演示路径：打开「碳核算Agent」（默认首页）→ 看到示例厂总量与排放结构 →
展开输入项填入电力因子 0.5366 → 总量从「待配置」变为具体值 →
改烟煤量做情景模拟看减排 → 点「取回收量做原料输入」看范围三减排贡献与口径提示。
