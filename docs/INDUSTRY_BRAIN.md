## 二、这个模块做了什么

在原有助手里新增「产业大脑」标签页，把五条业务链接进共享数据底座：

```
        采购 → 生产 → 销售 → 仓储物流 → 资金财务
          └──────── 共享数据底座 ────────┘
                        │
              五域领域智能体（rule / llm）
                        │
                 产业大脑总编排
```

代码位置：`src/paper_recycle_agent/brain/`

| 文件 | 职责 |
| --- | --- |
| `domains.py` | 五条业务链定义：KPI、职责、跨域影响、对华泰的规模对标说明 |
| `engine.py` | 共享数据底座 + 12 条跨域联动规则 + 确定性推演 + 管理干预 |
| `intelligence.py` | 五个领域智能体 + 产业大脑总编排，复用 `llm.py` |

### 跨域联动（这是"贯通"的核心）

不是五个孤立的看板——一个域的 KPI 变化会传导到下游。例如：

- 采购成本指数下降 → 生产成本下降 + 财务费用下降
- 原料合格率上升 → 生产合格率上升 + 断纸风险下降
- 生产合格率上升 → 订单满足率上升
- 交货时间缩短 → 财务费用下降

12 条联动规则全部声明在 `engine.LINK_RULES`，每条带影响系数，
可以用「管理干预推演」改一个 KPI，实时看到五条链怎么一起变。

## 三、与「智能工厂」模块的关系

- `mill/`（v1.7.0）：聚焦**生产车间内部**，四道工序智能体 + 机器狗/AGV 调度
- `brain/`（本次）：聚焦**企业全局**，五条业务链贯通与跨域决策

两者是"车间层"与"经营层"的关系，各自独立、互不依赖，共用同一个 `llm.py` 配置。

## 四、安全与口径边界

1. **纯仿真**：不连接任何 ERP / MES / 供应链 / 财务系统，所有 KPI 为仿真生成；
2. **建议而非指令**：领域智能体的输出是经营建议，真实决策由人做出；
3. **口径三级标注**：本项目仿真值、华泰公开成效（带来源）、常识性工艺区间，三类严格分开；
4. **可复现**：固定 seed（默认 2026），同样种子得到同样推演序列。

## 五、接口与演示

接口：`GET /api/brain/state`、`POST /api/brain/run`、`POST /api/brain/advise`、
`POST /api/brain/optimize`、`POST /api/brain/reset`

演示步骤：打开「产业大脑」→ 点「推演 5 步」看 KPI 变化与联动日志 →
点「领域智能体会商」看五条链的建议 → 在「管理干预推演」把采购成本指数调到 82，
看它如何传导到生产与财务 → 对照「华泰公开成效」理解真实系统的目标方向。
