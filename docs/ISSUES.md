## 关键决策记录（ADR 摘要）

**#15 为什么下线市、县两级**
市级、县级废纸回收量没有公开的权威统计。v1.2 用权重分摊生成市县数据，虽然能让「下钻」看起来完整，
但使用者无法分辨哪些是真实数字。与其给出看起来精确、实际是编造的数据，不如明确只给两级并标注数据性质。
这是本项目最重要的一次「减法」。

**#16 为什么分类数据标注为「估算」**
GB/T 20811-2018 只规定分类技术要求，官方不逐类公布回收量。因此分类回收量只能是
「结构占比 × 官方回收量」，占比本身来自行业经验值。全部字段带 `provenance`，界面与 Excel 都写明，
避免被当成统计公报数据引用。

**#23 为什么把下限降到 3.7，而不是干脆支持 3.6**
全仓库唯一的版本门槛是 `dataclasses`（3.7 引入），没有用到 walrus、`match`、`removeprefix`、
`zoneinfo` 等更高版本特性。降到 3.7 是零成本的；要再降到 3.6 就得把两个 dataclass 改写成
普通类，收益不足以抵消可读性损失。更重要的是：**声明支持哪个版本，就必须有办法验证**，
所以同时引入了 `tools/check_compat.py`，用 3.7 语法树解析全部源码并扫描 3.8/3.9 专有 API，
CI 每次都会跑。没有校验的版本声明只是一句口号。

**#24 为什么 openpyxl 必须变成可选依赖**
原实现在 `exporter.py` 顶层 `from openpyxl import ...`，而 `__init__.py` 又 import 了 exporter，
结果是「没装 openpyxl」这台机器连 `import paper_recycle_agent` 都会失败——命令行、离线版全部不可用。
改成按需导入后，缺依赖只影响导出这一个动作，且失败信息从 500 堆栈变成
「执行 pip install openpyxl，或改用离线版」这样的可执行指引。

**#25 为什么启动脚本里一个中文都没有**
实测两种写法都不可靠：`.bat` 由 cmd.exe 按控制台代码页逐行解析，UTF-8 中文会切断语句
（`!PYEXE!` 被拆成 `e`、`exe` 去执行）；给 UTF-8 文件加 BOM 则会让首行变成「BOM + @echo off」，
`@echo off` 直接失效、每行都回显。GBK 编码在中文系统上能用，但一旦系统开了
「Beta: 使用 Unicode UTF-8」就又崩。唯一在任何语言环境下都安全的做法是**纯 ASCII 脚本**，
中文说明放到 README / USAGE 里。

**#26 为什么不存在「企业投入产出表」，地级市也没有**
投入产出表是**国民经济核算工具**，编制主体是国家或地区统计局，用于刻画产业部门之间的
中间投入与最终使用关系。企业的法定报表是资产负债表、利润表、现金流量表——**没有任何企业
编制投入产出表**，也不存在这样的公开数据集。国家统计局在公开咨询答复中同时明确：
**目前地级市暂不编制投入产出表**，该表只到国家与省级两级。

因此原始需求的四级里，真正有官方表可依的只有两级。项目没有为了「看起来完整」去编造：
`LEVELS` 中每个层级都带 `io_available` 布尔值，市级标 `False` 并写明「按企业名录城市分布
分摊」，企业级标 `False` 并写明「企业无投入产出表，按年经手量 × 市场均价估算」。
前端与 Excel 会把这个标记直接显示出来。

**#26 为什么金额标「下限」而不是乘一个加价系数**
废纸消耗金额 = 消耗量 × 加权参考价。但 888.5 元/吨是**居民/回收站口径**的回收参考价，
纸厂到厂价还要叠加分拣、打包、运输，通常更高。最省事的处理是乘 1.2 之类的系数，
但那个系数没有任何公开出处，属于凭空引入的假设。宁可给一个明确标注的下限
（`is_lower_bound=True`，界面/Excel/文档三处同文说明），也不给一个看起来精确却无法溯源的数。

**#27 为什么地图不内置密钥，也不自己画中国地图**
中国地图的国界线、台湾岛、南海诸岛画法有明确合规要求，不能用 SVG 自行绘制「大致形状」。
可用的只有持牌地图服务商（腾讯 / 高德 / 百度 / 天地图）。代码里不写任何可用 key，
只留一句显式占位符，由使用者用环境变量 `TMAP_KEY` 注入。
无密钥时不报错、不白屏，降级为省份排行条形榜并给出申请链接——这是「能跑起来」和
「装完发现一片空白」的区别。

**#28 为什么密钥永不回传，且未配置时要回落而不是报错**
`public()` 只返回 `mask_key()` 后的 `sk-…3f9a`；`save_config(api_key=None)` 表示保留旧密钥；
`_scrub()` 在抛错前把文本里出现的密钥替换掉，因为部分服务端会把 key 回显在错误体里。
未配置时 `/api/llm/chat` 直接走规则引擎并在响应里带 `llm_error` 说明原因——
「装了能用大模型，不装也能用」比「必须配好才肯说话」更符合工具属性。

**#29 为什么麦克风要看波形，不能只看权限**
v1.4 只判断 `getUserMedia` 是否抛异常，于是出现「权限给了、按钮亮了、说话没反应」——
设备存在但录不到声音（系统静音、选错输入设备、驱动级禁用）。
现改为录 3 秒真实音频流、算 RMS 峰值，分三档给结论（<1% 几乎无声 / 1–5% 太弱 / >5% 正常），
并列出全部输入设备供选择；同时检查 `window.isSecureContext`——`http://` 非 localhost
环境下浏览器根本不给麦克风权限，这是「点了没反应」最常见的原因。
